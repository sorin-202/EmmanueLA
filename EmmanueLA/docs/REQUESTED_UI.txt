# 1. Settings — pagina principală

```text
SETTINGS                                      ◇
                                              Advanced

General
    System
    About

Your space
    Home
    App List
    Folders
    Appearance
    Gestures
    Apps
    Mindful Use
    Live the Moment
    Private Space
```

### Aspect

- `SETTINGS` mare, sus stânga.
- Buton `◇` sus dreapta. 
- `General` și `Your space` sunt titluri mai mari.
- Meniurile sunt rânduri simple.
- Fără descrieri lungi.
- Fără toate submeniurile afișate simultan.
- Tap pe un rând → pagină nouă.
- Back → revine un nivel.

Exact direcția pe care ai stabilit-o: pagina principală arată doar categoriile, iar opțiunile apar după tap. Pasted text

# 6. Arrange Widgets

Nu este meniu clasic.

Se deschide **direct în preview fullscreen**, dar aplicatiile favorite nu pot fi mutate.

```text
┌───────────────────────────────┐
│                               │
│             21:42             │
│         Wednesday 30          │
│                               │
│              19°C             │
│                               │
│                               │
│ Instagram                     │
│ Spotify                       │
│                               │
│                         82%   │
│                               │
│                               │
│ Reset                  Done   │
└───────────────────────────────┘
```

Interacțiuni:

```text
Drag       → move
Pinch      → resize
Tap        → widget options
```

Tap pe widget:

```text
WEATHER

Small   Medium   Large

Alignment
Left   Center   Right

Remove widget
```

Fără coordonate absolute.

# 34. Reguli vizuale pentru toate meniurile

Ca să fie coerentă toată aplicația (tine cont ca unele telefoane au notch, asa ca pastreaza o margine superioara care sa evite ascunderea textului de catre notch):

```text
Page title
26–30sp

Section title
14–16sp
medium/bold

Row title
16–18sp

Secondary value
14–16sp
lower opacity
```

Structura:

```text
PAGE TITLE

Section

Setting                    Value >

Setting                         ON

Setting                    Value >
```

Evita:

- card în jurul fiecărei setări;
- umbre multe;
- chenare inutile;
- texte explicative lungi;
- culori diferite pentru fiecare categorie.

Folosește:

- mult spațiu liber;
- separatoare foarte subtile;
- aceeași margine stânga peste tot;
- aceeași înălțime pentru rânduri;
- preview doar unde ajută efectiv.

Acesta ar fi tree-ul frontend pe care l-aș considera suficient de simplu pentru utilizare zilnică, dar destul de puternic după activarea `Advanced`.
