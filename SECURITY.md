# Security

EmmanueLA is a launcher and voluntary focus aid. Hidden/private apps and folder authentication protect launcher entry points; they do not encrypt other apps or create an Android work/private profile. Accessibility-based enforcement can be disabled by the device owner and depends on Android and OEM behavior.

Do not publish passwords, contact records, notification contents, configuration backups or unredacted usage logs in public issues. For a suspected vulnerability, use GitHub private vulnerability reporting if enabled for the repository. If that route is unavailable, ask the maintainer for a private contact before sharing sensitive details. No response-time guarantee is currently established.

Security fixes must preserve existing user data, recheck authorization at launch, and test denied/revoked permissions. Never log contact names, notification text, URLs or password material.
